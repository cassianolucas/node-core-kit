# Security Policy

## Supported versions

NodeCore is pre-1.0. Security fixes are applied to the latest published minor
version only.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository, under the **Security** tab. Include:

- the affected package and version
- steps to reproduce, or a minimal proof of concept
- the impact you expect

You can expect an acknowledgement within 7 days. We will confirm the issue,
prepare a fix, and publish a security advisory with credit to the reporter
unless you ask otherwise.
